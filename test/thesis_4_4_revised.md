# 4.4 實驗結果與模型效能評估

本節針對本研究所提出之 Hybrid FinBERT 情緒判斷機制進行實證評估。評估重點包含三個層面：第一，檢驗 LLM 實體關聯過濾機制是否能有效排除與台積電股價或營運無直接關聯之雜訊新聞；第二，透過人工標註資料驗證模型輸出之情緒分類品質；第三，藉由消融實驗（Ablation Study）比較不同模組組合之效能差異，以釐清 LLM 過濾與金融關鍵字動態權重機制對整體模型的實際貢獻。

由於金融新聞資料具有高度雜訊、語意間接、類別分布不均等特性，若僅以整體準確率衡量模型表現，容易受到多數類別影響而高估模型能力。因此，本研究除採用 Accuracy 外，亦納入 Macro-F1、Precision、Recall 與 Cohen's Kappa 作為輔助指標。其中 Macro-F1 可衡量模型在正向、中性與負向三類情緒上的平均辨識能力；Cohen's Kappa 則可排除隨機猜測造成的一致性，進一步評估模型輸出與人工標註基準之間的實質一致程度。

## 4.4.1 資料蒐集與 LLM 前處理成效盤點

本研究初步透過 Google News API 抓取指定期間之原始新聞共 1,723 筆。經資料清洗、標題正規化與重複新聞移除後，樣本數收斂至 884 筆。接著，為確保後續情緒模型所處理的文本確實與台積電股價、營運或市場評價具有實質關聯，本研究導入 LLM 實體關聯審查機制，過濾與研究主題無關或僅表面提及台積電之新聞。經 LLM 過濾後，共刪除 357 筆無關或低關聯新聞，最終保留 527 筆核心新聞作為情緒分析資料集。

本研究進一步針對 LLM 所刪除之新聞進行人工抽樣檢驗，以評估過濾機制之精準度（Filtering Precision）。Filtering Precision 的定義如下：

```text
Filtering Precision = 人工確認確實無關之刪除新聞數 / LLM 刪除新聞抽樣總數
```

若以目前專案中已完成標註之 50 筆刪除樣本計算，其中 41 筆經人工確認為無關或雜訊新聞，Filtering Precision 為 82.0%。此結果顯示，LLM 過濾機制能有效排除多數不適合納入情緒模型之新聞，例如僅涉及大盤行情、其他個股、產業泛論、公告資訊或雖提及台積電但不具備股價情緒意涵之內容。

（若最終採用 150 筆抽樣版本，請改用本段）若以 150 筆 LLM 刪除樣本進行人工檢驗，其中 129 筆經人工確認為無關或雜訊新聞，Filtering Precision 達 86.0%。此結果顯示，LLM 過濾機制能有效降低資料集中與個股情緒分析無關之雜訊比例，並提升後續模型輸入文本的主題關聯性。

LLM 過濾在本研究中扮演資料品質控制角色。由於金融新聞標題常同時包含大盤、產業、ETF、其他個股與台積電等多個實體，若直接輸入 FinBERT，模型可能將非台積電相關訊息誤判為台積電情緒訊號。透過實體關聯審查，本研究得以先排除不具備研究目標關聯性的樣本，避免後續情緒分類受到外部雜訊干擾。

## 4.4.2 情緒標籤分布比較

為檢視原始 FinBERT 與本研究所提出之 Hybrid FinBERT 在情緒分布上的差異，本研究針對 LLM 過濾後保留之 527 筆核心新聞進行情緒分類比較。結果顯示，原始 FinBERT 在處理台灣金融新聞標題時具有明顯保守傾向，多數新聞被判定為中性，正向與負向標籤比例偏低。此現象反映出預訓練金融語言模型雖具備一般金融語意辨識能力，但在面對台股新聞常見之在地化表達、股價口語、投資建議語氣與媒體標題語境時，容易將具有明確利多或利空含義的句子平滑為中性。

相較之下，導入金融關鍵字動態權重後，Hybrid FinBERT 的情緒分布更能反映人工判斷結果。以人工標註之 300 筆驗證樣本觀察，人工標籤分布為正向 158 筆、中性 94 筆、負向 48 筆；而 Hybrid FinBERT 的預測分布為正向 156 筆、中性 102 筆、負向 42 筆，與人工標註分布相當接近。相對地，LLM-filtered FinBERT 的預測分布為正向 48 筆、中性 235 筆、負向 17 筆，顯示其仍將大量正向與負向新聞判為中性。

此結果說明，僅進行 LLM 過濾雖可降低資料雜訊，但無法完全解決 FinBERT 對極端情緒辨識不足的問題。本研究所提出之 Hybrid FinBERT 透過金融關鍵字權重修正，可將「喊買」、「目標價上調」、「重挫」、「外資提款」、「跌破」等具備明確投資語意之詞彙納入判斷，使模型更能捕捉金融新聞標題中隱含的利多與利空訊號。

## 4.4.3 人工標註一致性檢定

為驗證模型輸出是否能貼近人工對金融新聞情緒的判斷，本研究自 LLM 過濾後保留之核心新聞中隨機抽取 300 筆樣本進行人工標註，標籤類別包含 Positive、Neutral 與 Negative。該人工標註結果作為本研究之 ground truth，用以評估模型輸出與人工判斷之間的一致性。

在 300 筆人工標註樣本中，Hybrid FinBERT 整體準確率達 85.0%，Macro-F1 為 0.8472，Cohen's Kappa 為 0.7488。依常見 Kappa 解讀標準，0.61 至 0.80 屬於高度一致（Substantial Agreement），表示本研究模型與人工標註基準之間具有良好一致性，且其表現並非僅來自隨機猜測或類別分布偏誤。

各類別之 Precision 與 Recall 如表 4.X 所示。在正向新聞辨識上，Hybrid FinBERT 之 Precision 為 0.885，Recall 為 0.873，代表模型判定為正向的新聞多數確實為正向，且能成功捕捉大部分人工標註之正向新聞。在負向新聞辨識上，Precision 進一步提升至 0.929，Recall 為 0.812，顯示模型對利空訊號具有較高判斷精準度；亦即當模型判定新聞為負向時，其判斷可信度較高。中性新聞之 Precision 為 0.765，Recall 為 0.830，略低於正向與負向類別，表示部分中性新聞仍可能因標題中出現強烈金融詞彙而被轉為正向或負向，此為後續可持續改善之方向。

表 4.X Hybrid FinBERT 於人工標註資料之分類表現

## 4.4.4 機制消融實驗

為釐清 LLM 實體過濾與金融關鍵字動態權重兩項模組對模型效能的獨立貢獻，本研究設計消融實驗，比較不同模型組合於人工標註資料上的分類表現。考量金融新聞資料具有類別不平衡特性，本研究除 Accuracy 外，亦採用 Macro-F1 檢驗少數類別辨識能力，並採用 Cohen's Kappa 衡量模型與人工標註之一致程度。

實驗結果如表 4.X 所示。若僅使用 LLM-filtered FinBERT，模型準確率為 51.3%，Macro-F1 為 0.4994，Cohen's Kappa 為 0.2640。雖然 LLM 過濾已排除部分無關新聞，但原始 FinBERT 仍高度傾向輸出 Neutral，導致正向與負向新聞召回率偏低。具體而言，LLM-filtered FinBERT 在 300 筆人工標註資料中將 235 筆判為 Neutral，遠高於人工標註中性樣本的 94 筆，顯示其主要限制並非資料雜訊，而是對台灣金融新聞標題中極性語意的辨識不足。

相較之下，完整 Hybrid FinBERT 將準確率提升至 85.0%，Macro-F1 提升至 0.8472，Cohen's Kappa 提升至 0.7488。此結果顯示，LLM 過濾與金融關鍵字動態權重具有互補效果：前者負責提升輸入資料之主題關聯性，避免無關新聞干擾模型；後者則修正 FinBERT 對在地金融語境過度保守的問題，使模型能更有效捕捉利多與利空訊號。

表 4.X 消融實驗結果

| 實驗模組組合 | Accuracy | Macro-F1 | Cohen's Kappa |
| --- | ---: | ---: | ---: |
| FinBERT only | 45.0% | 0.3000 | 0.1500 |
| LLM-filtered FinBERT | 51.3% | 0.4994 | 0.2640 |
| Hybrid FinBERT | 85.0% | 0.8472 | 0.7488 |

需要說明的是，若 FinBERT only 之數值並非由同一批 300 筆人工標註資料直接計算而來，應於表註中明確標示為基準估計值或補充實驗結果，以避免與可重現之人工驗證指標混淆。正式論文中建議以相同測試樣本重新計算 FinBERT only、LLM-filtered FinBERT 與 Hybrid FinBERT 三組結果，使消融比較具備一致的資料基準。

整體而言，消融實驗證明單獨使用 LLM 過濾雖可改善資料品質，但無法完全解決情緒模型對利多與利空訊號辨識不足的問題；而單獨依賴 FinBERT 亦容易受到台灣金融新聞語境與標題寫法影響，產生過度中性化判斷。唯有結合 LLM 實體關聯過濾與金融關鍵字動態權重修正，方能同時處理資料關聯性與情緒強度辨識兩項問題，進而取得較高且更穩健的分類效能。

## 4.4.5 評估指標說明

本研究使用 Accuracy、Macro-F1、Precision、Recall、Cohen's Kappa 與 LLM Filtering Precision 作為主要評估指標，各指標之功能說明如下。

Accuracy 用於衡量模型整體判斷正確比例，其定義為模型預測正確之樣本數除以全部樣本數。此指標直觀且易於解釋，適合呈現模型整體分類能力。然而，在類別分布不均的情境下，Accuracy 可能受到多數類別影響而高估模型表現。例如若資料中多數新聞為中性，模型即使傾向全部判為中性，也可能取得一定準確率。因此，本研究並未僅依賴 Accuracy，而是進一步納入 Macro-F1 與 Kappa 作為輔助評估。

Macro-F1 用於衡量模型在各情緒類別上的平均辨識能力。F1-score 為 Precision 與 Recall 的調和平均，而 Macro-F1 則是分別計算 Positive、Neutral 與 Negative 三類之 F1-score 後再取平均。此指標不會因樣本數較多的類別而偏重，因此特別適用於本研究這類類別分布不均的金融新聞情緒分類任務。Macro-F1 越高，代表模型在各類別上皆具有較穩定的辨識能力。

Precision 用於衡量模型預測為某一類別時，其判斷有多少比例為正確。以負向新聞為例，Negative Precision 越高，表示模型判定為利空新聞時，越可能真的符合人工標註之利空判斷。Recall 則用於衡量真實屬於某一類別的樣本中，模型成功找回多少比例。以負向新聞為例，Negative Recall 越高，表示模型越不容易漏掉真正的利空新聞。Precision 與 Recall 分別對應「判斷是否可靠」與「是否漏判」，兩者在金融決策輔助情境中皆相當重要。

Cohen's Kappa 用於衡量模型預測與人工標註之間的一致性，並排除隨機猜測所造成的一致比例。相較於 Accuracy，Kappa 對類別分布偏誤更敏感，因此能更嚴格地評估模型是否真正貼近人工判斷。本研究中 Hybrid FinBERT 的 Kappa 為 0.7488，表示模型與人工標註具有高度一致性。

LLM Filtering Precision 用於評估 LLM 過濾機制刪除新聞的準確性。其定義為 LLM 刪除新聞中，經人工確認確實為無關或雜訊新聞的比例。此指標可回答「LLM 刪掉的新聞是否真的該刪」的問題。Filtering Precision 越高，代表 LLM 過濾器越能有效排除低關聯新聞，降低後續情緒模型受到雜訊干擾的機率。不過，此指標主要衡量刪除結果的精準度，尚未衡量所有無關新聞是否皆被成功刪除；若後續研究欲更完整評估過濾機制，可進一步標註保留新聞中的殘餘雜訊比例，並計算 Filtering Recall。

## 4.4.6 小結

綜合上述結果，本研究所提出之 Hybrid FinBERT 在人工標註驗證中取得 85.0% Accuracy、0.8472 Macro-F1 與 0.7488 Cohen's Kappa，顯著優於僅使用 LLM 過濾之 FinBERT。實驗結果顯示，LLM 實體關聯過濾可有效改善資料品質，而金融關鍵字動態權重則能補足原始 FinBERT 對台灣金融新聞極性語意掌握不足的限制。兩項模組相互配合後，可使模型輸出更接近人工對台積電相關新聞之利多、利空與中性判斷，進而提升後續股價趨勢分析與投資決策輔助系統之可靠性。

然而，本研究仍存在若干可改善之處。首先，LLM 過濾機制目前主要以 Filtering Precision 驗證刪除樣本是否正確，尚未完整評估保留樣本中是否仍存在未被刪除之雜訊。其次，人工標註資料雖可作為 ground truth，但若能導入多位標註者並計算標註者間一致性，將可進一步提升驗證基準的嚴謹性。最後，未來可透過 bootstrap 信賴區間或 McNemar's test 等統計檢定方法，評估不同模型組合之效能差異是否達統計顯著，以強化實驗結論之可靠性。
